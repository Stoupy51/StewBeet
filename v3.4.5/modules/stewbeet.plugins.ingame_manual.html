    stewbeet.plugins.ingame_manual package#

    ingame_manual — modern, extensible, dialog-first in-game manual generator.

    Opt in by replacing stewbeet.plugins.ingame_manual with stewbeet.plugins.ingame_manual in your beet pipeline. See api (get_manual, Page subclasses, Phase, ButtonLayout, BakedText) for the customization API.

    copy_templates(
    config: ManualConfig,
    ) → None[source]#

    Copy bundled assets (and optional manual_overrides) into the temporary templates dir.

    beet_default(ctx: Context) → None[source]#

    Entry point: build the manual (reusing any Manual registered during setup).
