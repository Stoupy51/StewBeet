    A class representing a function header.

    path#

    The path to the function (ex: “namespace:folder/function_name”)

    Type:

    str

    within#

    List of functions that call this function

    Type:

    list[str]

    other#

    List of other information about the function

    Type:

    list[str]

    content#

    The content of the function

    Type:

    str

    executed#

    The execution context (ex: “as the player & at current position”)

    Type:

    str

    args#

    Dictionary mapping macro argument names to (type, description_lines) where description_lines is a list of strings (empty list if no description)

    Type:

    dict[str, tuple[str, list[str]]]

    Examples

    >>> header = Header("test:function", ["other:function"], ["Some info"], "say Hello")
>>> header.path
'test:function'
>>> header.within
['other:function']
>>> header.other
['Some info']
>>> header.content
'say Hello'
