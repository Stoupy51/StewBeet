      smithed_shaped_recipe(
      recipe: CraftingShapedRecipe,
      result_loot: str,
      ) → str[source]#

      Generate a Smithed Crafter shaped recipe.

      Note: Shaped recipe predicates must NOT include ‘count’ because smithed.crafter’s input storage omits count for individual slots. Shapeless predicates DO include count (the number of unique ingredient occurrences), which is handled separately.

      Parameters:

      • recipe – The recipe data.

      • result_loot – The loot table for the result.

      Returns:

      The generated recipe command.

      Return type:

      str

      static slot_predicate(
      ingredient: Ingr | None,
      slot: int,
      ) → JsonDict[source]#

      What a slot of a shaped recipe must hold, air when no ingredient goes there.

      Without a count, since smithed.crafter’s input storage omits it for individual slots.

      static slot_dump(
      predicate: JsonDict,
      ) → str[source]#

      >>> SmithedRecipeHandler.slot_dump({"id": "minecraft:air", "Slot": 2})
