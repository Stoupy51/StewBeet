      🚚 migrate#

      stewbeet migrate [minimal|basic] [--dry-run] [--yes]: turn an existing datapack or resource pack into a StewBeet project.

      MIGRATION_TEMPLATES: tuple[str, ...] = ('minimal', 'basic')[source]#

      Templates a pack can be migrated onto. The extensive one ships example content that would mix with the pack’s.

      migrate_command() → None[source]#

      Parse the command line, then migrate the packs found in the working directory.

      select_packs(
      working_dir: Path,
      ) → tuple[FoundPack | None, FoundPack | None] | None[source]#

      The datapack and the resource pack to migrate, or None after telling the user why there is nothing to migrate.

      download_template(template_name: str) → bytes | None[source]#

      The template archive matching the installed StewBeet version, or None after reporting why it could not be fetched.

      run_migration(
      working_dir: Path,
      template: ZipFile,
      datapack: FoundPack | None,
      resource_pack: FoundPack | None,
      *,
      dry_run: bool,
      assume_yes: bool,
      ) → MigrationPlan | None[source]#

      Show the plan, then apply it unless this is a dry run or the user declines.

      Returns:

      The plan when it could run (applied, unless dry_run), None when it was refused or cancelled.

      packs#

      Find the datapacks and resource packs a folder holds, before stewbeet migrate turns it into a project.

      SEARCH_DEPTH: int = 2[source]#

      How many folders below the working directory a pack is looked for.

      SKIPPED_FOLDERS: frozenset[str] = frozenset({'__pycache__', 'build', 'node_modules'})[source]#

      Folders never searched, on top of hidden ones: they hold outputs and dependencies, not sources.

      PLAIN_PACK_KEYS: frozenset[str] = frozenset({'description', 'pack_format'})[source]#

      Keys of the “pack” object that beet.yml and StewBeet already produce, so a pack.mcmeta holding only these can go.

      plan#

      Everything stewbeet migrate will do, worked out before anything on disk changes.

      A dry run prints the plan, a real run prints it and then applies it, so --dry-run shows exactly what happens.

      TEMPLATE_ICONS: tuple[str, ...] = ('src/pack.png', 'assets/pack.png')[source]#

      Where a template may keep its pack.png. The migrated icon goes wherever the chosen template has it.

      RESOURCE_PACK_CONFIG: str = '\n# Loads src/assets/, where `stewbeet migrate` moved your resource pack\nresource_pack:\n    name: "resource_pack"\n    load: ["src"]\n'[source]#

      Appended to a template’s beet.yml that only builds a datapack, when a resource pack is migrated.
