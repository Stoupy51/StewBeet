      ✨ Welcome to Stewbeet Documentation ✨#

      StewBeet#

      Minecraft datapacks, generated from Python. Declare an item or a block once, and every build writes its model, loot table, recipes, translations and in-game manual page.

      StewBeet is a set of plugins for beet, the build tool of the mcbeet team. Every beet plugin, and bolt and mecha, keep working in a StewBeet project.

      One definition, 8 files#

      This is the Life Crystal Block of Stardust Fragment:

      Block(
    id="life_crystal_block",
    vanilla_block=VanillaBlock(id="minecraft:glass"),
    recipes=[CraftingShapelessRecipe(
        ingredients=8 * [Ingr("minecraft:glass")] + [Ingr("life_crystal")],
    )],
)

      By hand, the same block is eight files in two packs: the place and destroy functions, its loot table, its vanilla recipe, its Smithed Crafter recipe, its item definition, its model and its translation key. StewBeet writes all eight from the definition on every build, so they never drift apart.

      Start a project#

      StewBeet needs only uv, which installs the Python version the template asks for.

      uvx stewbeet init
uv run stewbeet build

      The quickstart takes you from nothing to a loaded datapack, and the tutorial builds a whole pack step by step. Already have a datapack? Migrate it.

      An in-game manual of every item#

      The build turns your definitions into a book players open in game: every item, its recipes, and what it is used for, with the items drawn from their real models.

      What the build does for you#

      • Items and blocks: placement and destruction of custom blocks through Smithed Custom Block, block ticking, a loot table per item, paintings, an in-game manual of every item and recipe.

      • Recipes: vanilla crafting, smelting, stonecutting and smithing, Smithed Crafter recipes for items with components, furnace recipes through Furnace NBT Recipes.

      • Resource pack: models and item definitions found from the names of your textures, sounds and music discs, checks on texture sizes and on unused textures.

      • Text: plain text in your commands becomes translation keys collected in en_us.json, and a render key draws any item inside text.

      • Functions: Lantern Load loading with version checks, tick, second and minute clocks, scoreboard constants, an unload function, a header on every function.

      • Libraries: Bookshelf modules, Smithed libraries, Common Signals, Smart Ore Generation and the others are detected from your functions, downloaded for your Minecraft version and checked in game.

      • Output: reproducible zips, a merge with your libraries through Smithed Weld, a copy to your world after every build.

      Everything you don’t need to think about lists it all, and each plugin has its page.

      Editor support#

      The StewBeet extension for VS Code highlights and checks the commands inside your Python and your .bolt files, and links each built command back to the line that wrote it. See VS Code editor.

      Built with StewBeet#

      Datapacks, games and libraries with public source, from Stardust Fragment to Headconomics: the Showcase lists them all, and each card opens its source. Built something with StewBeet? Open an issue with its link.

      Contribute#

      • Report a bug or suggest a feature in the issues, or ask on Discord.

      • Pull requests are welcome. git clone --filter=blob:none https://github.com/Stoupy51/StewBeet downloads past files only when you need them.

      • The documentation lives in docs/web/public/docs/, one Markdown file per page and language.
