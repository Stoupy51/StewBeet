    Bases: BaseModel

    Configuration model for sorting operations.

    This class defines the parameters required to generate datapack functions that can sort lists stored in storage using various algorithms.

    Example: ```

    {

    “algorithm”: “selection_sort”, “functions_location”: “switch:stats/minigame/sort_leaderboard”, “to_sort”: {

    “storage”: “switch:stats”, “target”: “all.modes.sheepwars.played”

    }, “key”: “count”, “scale”: 100

    }

    ```

    algorithm: Literal['quick_sort', 'selection_sort']#

    Algorithm used to sort the elements, defaults to selection_sort.

    Namespaced id where the sorting functions are generated.

    The key to the number getting compared.
