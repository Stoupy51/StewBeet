The current problem with this auto lang file implementation is that
{"text":" attacks | ","color":"white"} and {"text":"attacks!","color":"green"} will end up with the same key, therefore conflicting.

I would like the auto lang plugin to automatically handle such cases by isolating the text in a list of text components.
For instance, the above example would be transformed into
- [{"text":" ","color":"white"},{"text":"attacks"}," | "]
- [{"text":"attacks","color":"green"},"!"]

This way, the keys and values will be the same
